# Project E62: User Role Management

**Status:** Done — 2026-06-04
**Epic:** E62 — User Role Management
**Phase:** Phase 14
**Primary Persona:** Kevin (Admin)

## Objective
Ensure all new sign-ups default to a 'customer' status, and provide a secure UI for Admins to manage and promote users to staff roles directly from the CRM Customer Detail page.

## Requirements
- Verify sign-ups default to 'customer'.
- Prevent non-admins from changing roles.
- Provide a UI for admins to view and update any user's role on their profile.
