# Disputes & Returns Management

As a staff member, you are responsible for managing customer return requests and charge disputes. Our platform prioritizes the **Makoonsii** persona's trust, ensuring that issues are resolved with minimal friction and plain language.

## Handling a Ticket

When a customer reports an issue via the storefront, a new ticket appears in the **Returns & Disputes** inbox (`/admin/disputes`).

1. **Review Request:** View the customer's description and the specific item details.
2. **Assign Resolution:** Determine the appropriate course of action (Refund, Exchange, or Store Credit).
3. **Staff Notes:** Use internal notes to document the resolution process. These are never visible to the customer.

## The Restock Workflow

When resolving a dispute, you have the option to **Restock** the item.

- **Automated Alerts:** If an item is restocked and set back to `Active`, the system will automatically fire alerts to any customers (like **Kevin**) who have a matching saved search. This happens within 60 seconds of the restock.
- **Police Hold Safety:** The system will automatically block restocking if an item has an active `Police Hold`. You must resolve the hold status before the item can return to the public storefront.

## eBay Integration

For items sold on eBay, use the `ebayDisputeId` to match our internal records with the eBay resolution center. This ensures that **Dale's** cross-border trust is maintained by providing consistent status updates across both platforms.
