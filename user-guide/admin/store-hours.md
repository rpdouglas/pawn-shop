# Store Hours

The **Store Hours** editor allows Managers and Admins to publish accurate operating hours across all four storefronts. Keeping hours current is especially critical during peak seasonal periods — Fireworks weekends, holidays, and special events.

## Getting There

Navigate to `/admin/store-hours` from the Admin Desktop Portal sidebar under the **Config** group.

## Updating Hours

1. Select the **day of the week** you wish to edit.
2. Set the **Open** and **Close** times using the time pickers.
3. To mark a day as **Closed**, toggle the closed switch rather than leaving times blank.
4. Click **Save** to publish the change immediately.

> Changes take effect as soon as they are saved — there is no staging step. Verify times carefully before confirming.

## Seasonal Overrides

During high-demand events (e.g., Canada Day Fireworks weekend), you may need to extend or reduce hours for specific dates without altering the regular weekly schedule. Use the **Date Override** panel to:

1. Pick a specific **calendar date**.
2. Set custom open/close times (or mark as closed).
3. Save the override. It will take precedence over the standard weekly hours for that date only.

Overrides can be removed at any time to revert to the regular schedule.

## Compliance Note

Accurate store hours directly affect the **Tanya Speed Test** — customers booking a Fireworks pickup window need a precise time slot, not an approximation. Outdated hours create mis-matched pickup confirmations and erode trust.
