# Store Scheduling

The scheduling system allows Managers to coordinate store coverage across all three views: Pawn, Cannabis, and Fireworks.

## Creating Shifts

1. Navigate to `/admin/scheduling`.
2. Click **Add Shift**.
3. Select the **Staff Member** from the dropdown.
4. Set the **Date**, **Start Time**, and **End Time**.
5. **View Assignment:** Choose which part of the store the staff member is assigned to (or "All / Floating" for general coverage).
6. **Notes:** Add specific tasks (e.g., "Deep clean electronics section").

## Managing the Schedule

- **Visual List:** Shifts are displayed in chronological order.
- **Deletion:** Managers can remove shifts by clicking **Delete**. This action is recorded in the system audit logs.

## Coverage Strategy

Use the schedule to ensure that specialized staff are available for the Cannabis and Fireworks sections during peak hours, satisfying the regulatory requirements for those views.
